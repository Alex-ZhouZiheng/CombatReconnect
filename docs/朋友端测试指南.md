# CombatReconnect 朋友端测试指南（macOS）

你不需要懂电脑，也不需要输入任何命令。遇到不明白的地方，截图发给主机，不要自己尝试修复。

## 测试前，向主机要两样东西

1. `CombatReconnect-macOS-test-kit-版本号.zip` 测试包。
2. 本次测试编号，例如 `CR-20260715-001`。

双方的测试编号必须完全一样。

## 第一次安装或收到新版本

1. 完全退出《Slay the Spire 2》。不能只回到主菜单。
2. 双击测试包 ZIP，把它解压成文件夹。
3. 打开解压后的文件夹。
4. 右键点击 `1-安装或更新CombatReconnect.command`，选择“打开”。
5. 如果系统再次询问，点击“打开”。
6. 看到“安装完成”后，按回车关闭窗口。
7. 启动游戏，在“设置 → Mods”中启用：
   - Combat Reconnect
   - STS2-RitsuLib
8. 主机要求关闭的其他模组也必须关闭。
9. 完全退出游戏，再重新启动一次。

以后如果主机发来新版本，需要重新执行以上步骤。

## 开始测试

1. 启动游戏，停在主菜单。
2. 双击 `2-朋友端测试日志工具.command`。
3. 输入 `1`，按回车，表示“开始测试”。
4. 输入主机发给你的测试编号，按回车。
5. 按主机告诉你的测试内容选择数字，再按回车。
6. 看到“已开始记录”后，按回车关闭窗口。
7. 回到游戏，按主机的说明加入房间和进行测试。

## 游戏报错、断线或卡住时

不要重新测试，不要退出或重启游戏，也不要删除任何文件。

直接执行下面的“结束测试”。如果游戏已经自己崩溃，也照常结束测试。

## 结束测试并发送日志

1. 再次双击 `2-朋友端测试日志工具.command`。
2. 输入 `2`，按回车，表示“结束测试并生成 ZIP”。
3. 等待窗口显示“测试结束”。
4. Finder 会自动选中一个 ZIP 文件。
5. 把这个 ZIP 原样发给主机，不要解压，也不要改名。

ZIP 通常在桌面的 `CombatReconnect测试` 文件夹中，名字类似：

`CR-20260715-001-client.zip`

## 如果双击文件没有反应

先尝试右键文件，选择“打开”。如果系统显示“无法验证开发者”：

1. 打开“系统设置”。
2. 进入“隐私与安全性”。
3. 找到刚才被阻止的文件，点击“仍要打开”。

仍然无法打开时，截图发给主机。

## 隐私提醒

游戏日志可能包含 Steam 编号和本机文件路径。只把测试 ZIP 发给你信任的主机或模组开发者，不要上传到公开群聊。
